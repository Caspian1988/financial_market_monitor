## ✨ Features

- **Live Market Feeds**: Asynchronously polls REST APIs for real-time prices and 24-hour performance percentage indicators.
- **Index Fund & Crypto Tracking**: Tracks major assets including Fidelity 500 Index Fund (FXAIX / S&P 500), Bitcoin (BTC), Ethereum (ETH), Solana (SOL), and Cardano (ADA).
- **Interactive Data Visualization**: Embedded Chart.js engine with custom timeframes (24 Hours, 7 Days, 30 Days).
- **Custom Price Alert System**: Client-side alert engine that triggers notifications when target price thresholds are crossed.
- **Minimalist & Ad-Free UI**: High-contrast, dark-mode dashboard tailored for quick readability without distractions.

---

## 🛠️ Tech Stack & API Integration

- **Frontend**: HTML5, CSS3 (Flexbox/Grid), Vanilla JavaScript (ES6+ `async/await`)
- **Data Visualization**: [Chart.js v4](https://www.chartjs.org/)
- **Icons**: FontAwesome v6
- **Data Source**: CoinGecko REST API (Public Endpoints)
